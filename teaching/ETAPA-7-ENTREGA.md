# Etapa 7 — Entrega y evaluación

**Herramientas:** Docker Compose, pytest, curl, Git, GitHub, logs, OpenAPI y
`corregir.py` del evaluador.

**Conceptos:** reproducibilidad, evidencia, métricas por campo, latencia,
tokens, costo, eliminatorias y documentación técnica.

La entrega incluye README, `docker-compose.yml`, `tests/`, mini-spec,
`INFORME.md` y estas guías. Se validan `martes-tranquilo`,
`fuga-sin-enlace`, A1-A4b, B1, B2, F1/F2, `sin_alerta_de_seguridad` y
`sistema_mudo`.

**Comandos:** `docker compose up --build`, `python -m pytest`, `curl
http://localhost:8000/health` y `git diff --check`.
